# Miixi – Sportkläder

Projektuppgift i kursen DT224G – Webbutveckling med HTML, CSS och JavaScript.

## Verksamhet
Webbplatsen presenterar Miixi och varumärkets sportkläder.

## Målgrupp
Personer som söker sportkläder för träning och en aktiv vardag.

## Syfte
Presentera varumärket och kollektionen samt hänvisa besökare
till miixi.se för köp.

## Planerade sidor
- Hem
- Kollektion
- Kontakt

## Planerad funktionalitet
- Responsiv layout
- Mobilmeny med JavaScript
- Kontaktformulär med JavaScript-validering
- Länkar till miixi.se
